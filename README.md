# BTVN01_LTWEB_PhamThiThuyQuynh_CNTT1K65
**Nêu chức năng chính:**
Student.cs -> quy định biết một sv gồm những thông tin gì
StudentValidator.cs -> quy tắc để 1 sv là sv hợp lệ
StudentService.cs -> các hàm chức năng
StudentConsoleView.cs -> hiển thị menu cho người dùng
MenuManager.cs -> dùng student service để xử lý các thao tác, dùng view để hiển thị thông tin
Program.cs -> để khởi chạy
**Cách dùng:** Vào file program.cs -> mở terminal mới rồi gõ lệnh "dotnet new console --force", sau đó gõ "dotnet run"
